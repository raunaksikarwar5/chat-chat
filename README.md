# LoveLink Chat

A simple real-time chat app for couples to talk in a shared room online.

## Features

- Real-time messaging with Socket.IO
- Shared room chat experience
- Live online user list
- Responsive romantic interface

## Run locally

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3005
```

## Tech stack

- Node.js
- Express
- Socket.IO

## Notes

Anyone who knows the room name can join the same room. If you want private invite-only rooms, I can add password protection next.
